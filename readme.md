# Трекер сна

Приложение для отслеживания сна и самочувствия. Фронтенд и бэкенд — в одном Google Apps Script веб-приложении (HTMLService). Каждый пользователь работает со своей таблицей в своём Google Drive; доступ к чужим данным невозможен.

## Структура

- `apps-script/` — файлы проекта Apps Script (копируются в редактор script.google.com):
  - `Code.gs` — серверная логика (хранение, API через `google.script.run`).
  - `Index.html`, `Css.html`, `Js.html` — интерфейс.
  - `appsscript.json` — манифест (скоупы и режим деплоя).
  - `Migrate.gs` — одноразовый перенос старых данных (удалить после использования).
- `index.html`, `css/`, `js/` — старая статичная версия (один пользователь, `fetch` + ключ). Больше не используется, оставлена для справки.

## Деплой

1. На https://script.google.com создайте новый проект.
2. Добавьте в него файлы из `apps-script/`: `Code.gs`, `Index.html`, `Css.html`, `Js.html` (и временно `Migrate.gs`).
3. Настройки проекта → включите манифест → вставьте содержимое `appsscript.json`.
4. «Развернуть → Новое развёртывание → Веб-приложение»:
   - Выполнять от: **пользователя, открывшего веб-приложение**
   - Доступ: **все, у кого есть Google-аккаунт**
5. Откройте URL `/exec` — при первом входе Google попросит разрешение (это нормально).

## Перенос старых данных

Запустите `migrateLegacy()` один раз из редактора (инструкция — в комментариях `Migrate.gs`), проверьте, что данные перенеслись, затем удалите `Migrate.gs` из проекта.
